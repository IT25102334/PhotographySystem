# Photography System

This is a group project for SE1020.

## Modules

* Customer Management
* Booking System
* Packages
* Staff Management
* Payment System
* Feedback System

## Technologies Used

* Java (OOP)
* JSP / Servlets
* File Handling (TXT files)
* GitHub

## Description

This system allows customers to book photography sessions, select packages, make payments, and provide feedback.

## Team Contribution

Each team member is responsible for one module and must implement CRUD operations.
